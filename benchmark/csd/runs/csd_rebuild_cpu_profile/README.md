# CSD rebuild CPU/GIL profile

Open `csd_rebuild_gil.chrometrace.json` in <https://ui.perfetto.dev/>.

The trace was generated by:

```bash
OUT_DIR=benchmark/csd/runs/csd_rebuild_cpu_profile \
ITERATIONS=200 RATE=100 \
bash benchmark/csd/eval/run_profile_csd_rebuild_gil.sh
```

Select the `csd-rebuild_0` thread and expand:

```text
rebuild_once
  build_csd_rebuild_payload_from_counts
    build_csd_hash_table_payload
      _try_build_hash_table
        _hash64
```

`py-spy --gil` only records Python threads while they own the GIL. Therefore,
the width of these frames directly represents time during which the scheduler
thread cannot execute Python.

For 200 rebuilds using the 1,052,300-entry production table:

| range | inclusive total | per rebuild |
|---|---:|---:|
| `rebuild_once` | 6435.3 ms | 32.18 ms |
| `merge_counts` | 250.8 ms | 1.25 ms |
| `filtered_keys` | 144.0 ms | 0.72 ms |
| `build_csd_hash_table_payload` | 6010.9 ms | 30.05 ms |
| `_try_build_hash_table` | 4658.6 ms | 23.29 ms |
| `_hash64` | 3043.6 ms | 15.22 ms |

Times are inclusive and must not be added together.
